OPTIONAL audio overrides. If a file with one of these names exists it is used instead of the synthesized sound:
  music.ogg, click.wav, jump.wav, land.wav, push.wav, hit.wav, fall.wav, countdown.wav, go.wav, victory.wav, crack.wav, whoosh.wav
The game works with this folder empty (all sounds are generated at startup by scripts/audio_manager.gd).
